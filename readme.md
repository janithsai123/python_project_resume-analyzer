# Smart Resume Screening System

## Project Overview

The Smart Resume Screening System is a Python-based application that automates resume analysis and candidate screening.

The system extracts candidate details from resumes, compares skills with job requirements, calculates ATS match scores, and generates hiring recommendations.

---

## Features

- Resume Parsing
- Skill Extraction
- ATS Score Calculation
- Match Percentage Analysis
- Hiring Recommendation System
- JSON Report Generation
- Modular Project Architecture

---

## Technologies Used

- Python
- Regular Expressions (Regex)
- JSON
- File Handling
